# MYTHØS Launcher

## Fonte oficial

Este diretório é a fonte oficial do Launcher APK da Mythøs Network dentro do repositório `Nyx_Roleplay`.

### Baseline

A linha visual e funcional de referência é o **MYTHØS Launcher 2.2 Polished**, fornecido em 14/08/2026.

Características da baseline:

- Landscape/20:9.
- Interface MYTHØS Network.
- Servidor fixo `51.68.107.75:10961`.
- Entrada direta por `samp://51.68.107.75:10961`.
- Sem tela para o usuário informar IP.
- Vídeo hero em tela cheia.
- Logo MYTHØS.
- Botão único de entrada no servidor.
- Preparação automática do fluxo de inicialização.
- Cliente/cache tratados pelo Launcher de forma controlada e compatível com as restrições do Android.

## Regra de projeto

Não colocar neste diretório GameMode, scripts Pawn, servidor ou código da rede social RPGRAM. O Launcher é o aplicativo responsável pela experiência de inicialização, atualização, preparação dos arquivos necessários e abertura do cliente SAMP Mobile.

## Estado atual

O projeto Android existente neste diretório permanece a base de compilação enquanto os componentes da versão 2.2 Polished são consolidados nele. A versão ZIP Expo 2.2 Polished é a referência de UX, não uma segunda linha de produto.
