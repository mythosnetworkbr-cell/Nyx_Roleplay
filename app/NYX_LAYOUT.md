# Nyx Roleplay — Layout do aplicativo

## Direção visual

Interface premium de roleplay urbano, escura e elegante. Fundo quase preto, superfícies em grafite e roxo Nyx como cor de ação.

## Tela inicial

- Logo Nyx centralizada.
- Botão principal: **JOGAR**.
- Botão secundário: **CONFIGURAÇÕES**.
- Indicador de servidor/conexão.
- Rodapé discreto: **MYTHØS NETWORK**.

## Navegação

1. Início
2. Servidores
3. Perfil
4. Configurações

## Componentes

- Cards com cantos arredondados.
- Botões altos e fáceis de tocar.
- Ícones simples e consistentes.
- Animações curtas de entrada e transição.
- Alto contraste para leitura no celular.
