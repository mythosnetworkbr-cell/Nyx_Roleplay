# Nyx Roleplay — produção

## Direção
Cliente Android em landscape, experiência de RP mobile inspirada na liberdade de um cliente FiveM, com identidade e conteúdo próprios.

## Fases
1. Core jogável: personagem, câmera, movimento, veículos e mundo 3D.
2. Mundo: cidades, ponte, mirante, NyxStore, bairros e serviços.
3. RP: empregos, economia, inventário, propriedades, organizações e progressão.
4. Social: chat global, atendimento/denúncias, chat administrativo e canais de organização.
5. Staff: hierarquia, invisibilidade, punições, logs e ferramentas Admin 2+.
6. Multiplayer: servidor autoritativo, sincronização, persistência e segurança.
7. Android: touch, qualidade gráfica, streaming de assets e builds APK/AAB.
8. Conteúdo: personagens, veículos, animações sociais, danças, áudio e UI final.

## Regras já definidas
- NXcoin é moeda premium, separada do dinheiro do RP.
- Alterar o nome do personagem custa 50 NXcoin.
- Admin 2+ pode usar ferramentas de veículos.
- Chat Admin é privado para staff.
- Chat de organização é privado aos membros da organização.
- Admin pode ficar invisível aos jogadores.
- Hierarquia de staff termina em Owner.

## Regra técnica
Toda ação sensível deve ser validada pelo servidor. O cliente Android nunca deve ser a autoridade para dinheiro, NXcoin, cargos, punições, inventário ou permissões.

## Conteúdo
Usar referências de gênero e UX de jogos RP existentes, mas implementar código, mapas, personagens, veículos, UI, áudio e outros assets próprios ou devidamente licenciados.
