# Nyx Roleplay — Base de migração

## Objetivo

Transformar a base do RPgram em um projeto identificado como **Nyx Roleplay**, mantendo a base original preservada e evitando alterações destrutivas.

## Identidade

- Aplicativo: Nyx Roleplay
- Marca: Mythøs Network
- Projeto-base: RPgram

## Regras da adaptação

1. Substituir nomes visíveis `RPgram` por `Nyx Roleplay`.
2. Substituir referências de marca antigas pela identidade Mythøs Network quando elas forem próprias do aplicativo.
3. Manter bibliotecas, código de jogo e arquivos necessários da base enquanto não houver uma implementação equivalente testada.
4. Não inventar IP, porta, credenciais ou serviços de backend.
5. Manter o pacote original `RPGRAM_GitHub_READY.zip` intacto como cópia de segurança.

## Próxima etapa técnica

O ZIP precisa ser extraído para que os arquivos internos possam ser renomeados e editados individualmente. A ferramenta GitHub usada nesta sessão não consegue ler ou modificar diretamente o conteúdo binário do ZIP; por isso, esta etapa não é considerada concluída apenas com a troca do README.
